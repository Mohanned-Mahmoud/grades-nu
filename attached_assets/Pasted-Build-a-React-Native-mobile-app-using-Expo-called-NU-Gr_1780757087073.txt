Build a React Native mobile app (using Expo) called "NU Grades Tracker" that monitors student grades from the NovaCampus Self-Service portal at https://register.nu.edu.eg/PowerCampusSelfService

## Core Features

### 1. Authentication
The portal uses a two-step JSON login:
- Step 1: POST https://register.nu.edu.eg/PowerCampusSelfService/SignIn/GetAuthenticationMode
  Body: {"username": "YOUR_USERNAME"}
  
- Step 2: POST https://register.nu.edu.eg/PowerCampusSelfService/SignIn/Authenticate  
  Body: {"username": "YOUR_USERNAME", "password": "YOUR_PASSWORD"}
  Headers: {"Content-Type": "application/json", "Accept": "application/json"}
  
After login, the session is maintained via cookies — use a cookie jar / cookie persistence in all subsequent requests.

- Step 3 (verify auth): POST https://register.nu.edu.eg/PowerCampusSelfService/Layout/InitialLoadData
  This returns JSON with "isAuthenticated": true and "displayName" if login succeeded.

### 2. Grades Fetching
After authentication, navigate to the grades page:
- GET https://register.nu.edu.eg/PowerCampusSelfService/Grades/GradeReport
  This is an HTML page — parse it with a DOM parser or cheerio to extract the grade table.
  The page contains a table with columns like: Course Code, Course Name, Credits, Grade, Points.
  Store all grades as an array of objects: { courseCode, courseName, credits, grade, points }

### 3. Background Polling & Notifications
- Poll for new/changed grades every 30 minutes in the background (use Expo Background Fetch + expo-task-manager).
- On first run, save the current grades snapshot to AsyncStorage as the "baseline".
- On every poll: compare new grades to stored baseline.
- If any grade changed or a new grade appeared that wasn't there before, send a local push notification (use expo-notifications) with the message:
  "📊 New grade posted: [Course Name] — [Grade]"
- Update the stored baseline after notifying.

### 4. Home Screen Widget
Use expo-widgets (or react-native-android-widget for Android) to create a home screen widget that shows:
- App name: "NU Grades"  
- A summary like "5 grades posted" or "No new grades"
- Last checked time
- The most recent new grade if available
The widget should update whenever the background fetch runs.

### 5. App Screens

**Login Screen:**
- Username and password text inputs
- "Login" button
- On success → navigate to Dashboard
- Store credentials securely using expo-secure-store

**Dashboard Screen:**
- Display student name (from InitialLoadData response "displayName")
- Show a list of all current grades in a nice card layout
- Each card shows: Course Name, Grade (large, colored green/yellow/red based on pass/fail), Credits
- A "Refresh" button to manually trigger a grades check
- "Last updated" timestamp
- Badge/indicator if new grades were found since last check

**Settings Screen:**
- Change username/password
- Set polling interval (15 min / 30 min / 1 hour)
- Enable/disable notifications
- "Logout" button that clears stored credentials

### 6. Tech Stack
- Expo SDK 50+
- React Navigation (stack + bottom tabs)
- AsyncStorage for grades cache
- expo-secure-store for credentials
- expo-notifications for local push notifications
- expo-background-fetch + expo-task-manager for background polling
- react-native-android-widget OR expo-widgets for the home screen widget
- axios or fetch with cookie handling (use react-native-cookies or tough-cookie)
- Use a clean modern UI with the university colors: dark navy blue (#1B3A6B) and gold/yellow (#F5A623)

### 7. Important Technical Notes
- The portal is ASP.NET MVC and uses session cookies — you MUST persist cookies between requests using a cookie jar
- All API calls must include headers: {"Accept": "application/json", "Content-Type": "application/json"}
- The grades page is HTML, not JSON, so you need to parse HTML — use react-native-html-parser or fetch the page and use regex to extract table rows
- Handle session expiry: if a request returns 302 redirect to login page, re-authenticate automatically using stored credentials
- Handle network errors gracefully with retry logic
